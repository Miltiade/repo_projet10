# softdesk_support

## Description  
Projet backend sécurisé pour une application de support technique B2B, développé avec Django REST Framework.

## Prérequis  
- Python 3.12.3  
- Pipenv  

## Installation  
1. Cloner le dépôt :  
   ```bash
   git clone https://github.com/miltiade/repo_projet10.git
   cd repo_projet10/P10
   ```

2. Installer les dépendances :

    ```bash
    pipenv install
    ```

3. Activer l’environnement virtuel :

    ```bash
    pipenv shell
    ```

## Lancement du serveur local

```bash
python manage.py runserver
```

Le serveur est accessible à l’adresse http://127.0.0.1:8000.
